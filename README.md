## 持续交付

每项同时完成业务流程、GUI/3D、权威数据、领域端口、异常/失效、理论来源、扩展边界、验收和工作包关联。GUI/CLI/Agent共用领域入口；公共层统一身份、单位、坐标与协议，不建立巨型业务对象。规划阶段完成后停止本规划任务，产品实现、设计批准和实机验证仍按各自流程推进。
