# Procet Studio 开发规划与业务设计

本仓库统一维护 Procet-* 新架构的业务能力、界面设计、数据契约评审、实施工作包和验收规格。

## 维护方式

- 已交付文档逐步迁入 Git，后续不再以 ZIP 作为主交付方式。
- 按 `CAP-xx-xx` 逐项完善业务功能；按原编号细化36项工作包。
- 每项同步说明业务流程、界面交互、数据所有权、模块接口、扩展边界和验收条件。
- 文档编制、设计评审、代码实现与产品验收分别记录，不用文档检查通过代替产品验收。
- 中文文档、中文提交说明；不启动付费 CI，不修改业务仓库或用户数据库。

正在迁入 V0.8 架构基线、第00批交付说明与第01批10项业务功能深化资料。完整目录、逐项台账和校验记录将在迁移提交中更新。
