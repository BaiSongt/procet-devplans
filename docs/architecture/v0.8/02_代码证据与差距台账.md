## 官方参考资料

### R01 · ISO/IEC/IEEE 42010:2022：Architecture description
https://www.iso.org/standard/74393.html

用于多视点架构描述；不将建议层次说成标准强制架构。

### R02 · LinuxCNC：Stand Alone Interpreter
https://linuxcnc.org/docs/html/code/rs274.html

参考控制器解释独立入口，不替代商业控制器专有语义。

### R03 · LinuxCNC：Kinematics
https://linuxcnc.org/docs/html/motion/kinematics.html

区分坐标轴、机械关节及正逆运动学。

### R04 · The Cargo Book：Specifying Dependencies
https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html

仓库和 crate 的边界不同；明确 git rev/path 消费方式。

### R05 · ISO 841:2001：Coordinate system and motion nomenclature
https://www.iso.org/standard/23949.html

机床坐标与运动命名依据；具体设备参数仍需厂家资料与实测。

### R06 · W3C：Understanding SC 4.1.3 Status Messages
https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html

状态可读与可访问反馈指导，不宣称认证。

### R07 · NIST：Defining requirements for integrating information between design, manufacturing, and inspection
https://www.nist.gov/publications/defining-requirements-integrating-information-between-design-manufacturing-and

借鉴设计、规划、执行、检测之间的数据谱系与来源关联。
