## U4-02新增工程规则与验收范围

[原U4-02工作包](../../work-packages/U4-02.md)已约定脏稿三选、统一任务贡献、CAS及晚回执隔离，但原WCAG来源尚未有原同名Trace显式指向。本次补证要求：脏稿离开时焦点处于有标签模态内部、焦点次序维持操作意义、键盘焦点可见且不被作者内容完全遮挡；模态关闭回到触发元素，若已不存在则须选择合理工作流替代焦点。Esc取消导航保全草稿，且晚回执不得更改新scope。此处**焦点要求**来自WCAG §2.4.3/2.4.7/2.4.11及W3C APG Dialog指导，**CAS/取消/晚回执**是独立的业务工程约束，不能虚称WCAG规定事务。

基础字体≤12px与正常交互目标24×24 CSS px分别评估，例外需人审；左侧唯一TaskPanel、唯一活动Babylon 3D及GUI/CLI/Agent同一领域Port仍为系统约束。原U4-02→CAP-04-01直接边保留，CAP-01-07仅跨域消费者候选，不扩写原CAP关系。
