# CAP-02-03｜刀柄与刀具总成

版本：V0.10评审稿｜2026-10-16｜编制完成，待设计评审；产品实现与验收未执行。

原始能力：主轴接口、刀柄、延长杆、刀尖基准。主责：制造资源；消费方：Setup、CAM策略、后处理/NC执行、机床运动、Renderer。主要关联工作包：F1-02、F1-06、E3-04；补充关联B0-03、E3-03、U4-02、U4-03。不得据本项完成自动将这些工作包标为完成。

## 1. 用户目标与边界

工艺员需要明确“这把刀由什么组成、从哪个基准安装、实际刀尖在哪里、哪套装配可以用于当前任务”。资源维护员管理标准件和总成版本；工艺员选用已发布总成；对刀人员形成实测与执行配置；验证人员核对证据。A探索可使用显式假设的草稿，但B生产采用必须满足对应精确引用与适用性要求。

本项拥有总成定义、子件精确引用、相对安装、控制点、尺寸来源和适配结论。它不拥有具体机床FK/IK、实时轴状态、工序切削条件、控制器H表的执行状态，也不在此实现材料扫掠仿真。

## 4. 端到端主流程

1. 从ActivityRail“制造资源”或Setup中的总成选择入口打开同一任务容器。若来自Setup，保存返回作用域与选择令牌；独立资源维护不伪造项目作用域。
2. 新建总成草稿或从已发布版本派生。资源列表默认展示明确生命周期，历史修订可查看但不自动使用latest。
3. 选择根刀柄，再按配合关系添加子件；单根、无环、可追踪父子端口。不允许用树中的上下位置猜真实安装关系。
4. 后端解析精确资源及接口，返回兼容/不兼容/未知。未知可保留草稿，但界面必须说明缺少什么来源。
5. 设置可编辑的装配参数。派生量规长、TCP和外包络统一由领域服务计算；3D按返回的节点变换显示。
6. 查看安装基准、夹持端面和TCP标记，检查轴向尺寸起止点。重复“重新计算”必须幂等。
7. 预检列出当前草稿锁版本、子件修订、计算版本和问题。发布时服务端重算并检查同一指纹，不能凭前端绿色标签放行。
8. 发布成功形成新修订。来自Setup时，返回已发布ExactAssemblyRef，由原Setup的命令再次验证作用域和版本后采用；本页不直接修改已批准Setup。

替代流程：没有接口资料→保存待补证草稿；子件已更新→继续使用原精确版本或显式派生，不静默升级；总成只用于展示→明确display_only，不授生产资格；对刀实测→通过执行配置创建校准快照，不改写已发布名义资源。

## 5. 页面与交互规格

### 5.1 统一容器布局

沿用宿主固定宽度token，不新建业务专用抽屉、横向中心Tab或第二Canvas。容器标题为“刀具总成｜名称｜修订”，右侧关闭；标题下显示“草稿/只读/来源不足/已发布”和“返回Setup”上下文。

容器内部按纵向任务区组织：总览→组成与接口→安装尺寸与TCP→校验与发布。长内容用分组折叠和列表虚拟化，不把所有参数堆在一屏。底部固定动作区为保存草稿、预检、发布/采用；关闭始终可用，脏草稿选择保留、放弃或取消关闭。

资源3D与主工程3D使用同一世界的横向空间切换，保留各自相机；不并排创建主视口。资源浏览保持整体可见，编辑尺寸时聚焦对应构件，不能突然重置全部相机。

### 5.2 具体区域

| 区域 | 内容与用户动作 | 数据和显示规则 |
|---|---|---|
| 概要卡 | 总成名称、资源代码、生命周期、当前TCP类型 | 名义参数与实测状态分列 |
| 组成树 | 根刀柄→连接/延长件→夹持件→刀具，显示子件Rev | 点击选中真实nodeId；不得使用meshId存档 |
| 接口卡 | 父端口、子端口、规格、匹配结果、来源 | 不兼容红色、未知带文字，不能只靠颜色 |
| 尺寸卡 | 伸出、插入/接合、量规长、方向 | 输入与派生只读字段明显区分，显示单位与两端基准 |
| TCP卡 | 参考点类型、位置、方向、名义/校准来源 | 球心与最低点不能混名；不提供无来源“一键修正” |

### 5.3 3D选择、预览、确认

选树节点与选3D构件双向同步，必须保留nodeId、resourceRevision和sceneRevision。无精确映射的网格只能显示选中，不能接受安装关系。拖动或尺寸手柄只创建预览租约；鼠标释放形成草稿编辑命令，按Escape撤销该次预览，不撤销其他已保存草稿。

坐标标记显示A总成根、各配合接口和P控制点；工程轴向由后端frame定义。尺寸线说明起止面；不要把视觉最上端当量规面。接口选择可以点击带语义的端口标记，但任意几何面不自动成为安装接口。状态和单位进入底部状态栏，避免悬浮HUD遮挡。

### 5.4 状态矩阵

| 状态 | 可操作 | 不能发生 |
|---|---|---|
| Loading | 取消、返回 | 旧异步结果覆盖新总成 |
| Draft clean/dirty | 编辑、预览、保存、预检 | 把预览写入已发布资源 |
| Missing evidence | 保存草稿、跳转补证 | 以默认零值消除未知 |
| Conflict | 查看差异、重新载入或派生 | 静默覆盖他人修订 |
| Released/历史 | 浏览、选用或派生 | 原位改尺寸 |
| Retired | 历史查看；新采用按策略阻断 | 删除历史工程依赖 |
| Backend unavailable | 查看缓存并标只读 | UI已加载就显示“验证通过” |

## 6. 字段级设计

下表为目标语义，不是对既有JSON立即改名。复用字段和新增字段要经版本化适配。

| 字段/对象 | 来源与可编辑性 | 约束与归属 |
|---|---|---|
| resourceId/revisionId/draftLockVersion | 服务端产生，只读 | Draft锁与工程修订不是同一个数 |
| nodes[].resourceRef | 用户选择，服务端解析 | 精确子件rev及内容身份，禁止latest |
| nodes[].parentNodeId | 组成编辑 | 单根无环，引用存在；多余悬空节点拒绝 |
| interfaces[].interfaceRef | 标准件/厂家资料 | 类型、尺寸系列、角色、定位基准和来源 |
| connectionTransform | 经配合规则确定或明确受控输入 | parent/child frame与单位完整；不是随意拖放值 |
| cutterStickoutMm | 装配输入或实测来源 | 非负且满足该刀具/刀柄的证据化范围 |
| clampingEngagement | 实际配合计算/证据 | 不能由整体外形长度无条件推定 |
| nominalTcpTransform/tcpKind | 由刀具和装配推导，只读 | 完整位姿、参考点类型与推导版本 |
| nominalGaugeLengthMm | 受限同轴模型派生，只读 | 起止面/方向明确；非同轴不冒充一个标量 |
| declaredGaugeLength | 厂商声明，可录入来源 | 与计算值冲突应报告，不能覆盖计算值 |
| calibrationRef | 执行侧校准快照，只读引用 | 绑定总成修订、方法、时点与误差来源 |
| controllerOffsetBinding | D10执行配置 | 标明绝对/相对等方法；不等于资源量规长 |
| displayGeometryRef/collisionGeometryRef | 资源几何提供者 | 分级，不以显示代理冒充精确碰撞体 |
| applicability/unknownReasons | 领域校验输出，只读 | 缺额定值不视为无限能力 |

默认值：身份/锁由服务端产生；单位来自工程/资源约定；接口参数来自选定资源；未知安装尺寸、最小夹持量、额定转速均无臆造默认值。无父子定位证据不能用单位阵凑齐。

## 7. 底层统一数据与模块责任

D03拥有名义总成及能力；D04保存工艺装夹选用关系；D10绑定具体机床、校准与刀补方法；D13解释控制器补偿状态；D14生成轴运动；D15记录程序级验证。公共C0只承载统一身份、版本、坐标引用、作用域和回执，具体ToolAssembly语义留在资源C1。

逻辑接口提案：

| 名称 | 输入 | 输出/失败语义 |
|---|---|---|
| QueryAssemblyRevision | exactRef | 名义快照、节点/接口、来源；unknown_revision |
| ProposeAssemblyRevision | baseRef可选、typed子件及连接、幂等键 | 新草稿与draftLockVersion；重复键不同输入报冲突 |
| UpdateAssemblyDraft | draftId、expectedLock、typedPatch | 原子新草稿；revision_conflict不部分写入 |
| PreviewAssemblyValidation | draftId、expectedLock、算法/规则配置 | 派生几何、问题、依赖指纹；不是发布凭据本身 |
| ReleaseAssemblyRevision | draftId、expectedLock、previewFingerprint及必要批准 | 服务端重验后的exactRef和receipt；stale_preview拒绝 |
| ResolveAssemblyUse | exactRef、用途、机床接口可选、返回作用域 | compatible/incompatible/unknown及原因；不直接修改Setup |

应用入口统一供GUI/CLI/Agent使用。资源服务拥有配合与装配推导，机床运动服务拥有机床FK/IK，执行适配拥有补偿语义，Renderer只拥有显示派生。C1字节、审查记录和快照协议各自版本化；未知影响工程含义的扩展不得静默忽略。

## 8. 并发、变更与恢复

保存、预检、发布都带精确Draft锁。预检后子件或草稿改变，旧预检失效。切换资源/工程/Setup时增加作用域代次，撤销预览和选择租约；旧回执保留为任务记录，不能覆盖新现场。

派生新总成不改历史Setup。用户明确替换后，以实际声明的依赖传播失效：消费总成身份/几何的CL结果须重新评估；D10及下游NC/执行/验证按依赖更新。不能一概说换刀柄不影响CL，也不能无条件清空全部工程。未声明依赖分片的旧产物应保守失效，不能为了缓存复用跳过校验。

离线快照包含总成、精确子件、接口依据引用、必需几何和已选校准记录。恢复缺必要子件则事务失败或显式只读降级；不得回退查找本机最新资源形成伪成功。
