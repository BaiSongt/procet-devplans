# CAP-02-04｜业务驱动界面与字段规格

状态：界面规格评审稿，不是可运行原型或已接线页面。配套[功能规格](README.md)。保持一个Babylon世界、固定宽度左侧统一任务容器、主/资源空间横向切换、浅/深主题。不得增加并排第二视口或为本功能另造右侧抽屉。

## 1. 两个入口，同一对象

资源管理入口：ActivityRail制造资源→夹具与工装，打开目录和资源空间。Setup选用入口：Setup装夹任务→选择资源；记录callerScope={projectId,documentInstanceId,setupId,baseRevision,editSessionId,epoch}。返回时再校验该作用域仍有效，不从当前活跃文档猜测接收者。

上部固定摘要：资源名称、exact修订、资源生命周期、只读原因。五个任务区共用容器：①目录与版本；②总成与组件；③接口与基准；④驱动与夹持范围；⑤检查与采用。任务区导航是该面板子任务，不新建全局stage真值。较长参数纵向滚动；操作栏与标题不随列表滚走。

空间中只显示当前任务所需的底座、组件、接口坐标架与选中基准；隐藏几何不等于删除或取消碰撞参与。资源空间与工程空间切换时保留相机、选中对象和草稿作用域，不重新创建Engine。

## 2. 五个页面的主要操作

| 页面 | 用户看到什么 | 主动作 | 3D反馈 |
|---|---|---|---|
| 目录与版本 | 类型、编码、修订、状态、资料/资产完备性；已选历史修订单独标识 | 查看；派生草稿；选择该修订 | 预览选中资源，无Setup写入 |
| 总成与组件 | 基座/总成、固定/活动组件、几何资产及用途 | 添加/移除组件；绑定资产 | 对应组件高亮；无几何显示明确线框/标记，不假装精确实体 |
| 接口与基准 | mounting/child接口、刚性/格点/槽/轨道允许域、局部datum角色 | 添加/编辑接口；从模型选点/面；查看来源 | 显示局部轴、法向、允许安装域；mesh-only只能显示选择 |
| 驱动与夹持范围 | manual/mechanical/pneumatic等类型、开口/直径范围、运动轴、资料 | 保存能力草稿；测试显示预览 | 开合动画仅为预览，不标实夹紧、不驱动NC验证 |
| 检查与采用 | 分项结论、缺失条件、来源、输入版本、受影响成果 | 保存草稿；请求发布；返回Setup；在Setup应用 | 仅显示此检查输入对应的几何和问题定位 |

资源发布按钮与Setup应用按钮不在同一语义下复用。发布修改D03；采用修改D04。读取历史修订时只保留“派生”和“选用”等合法动作。

## 3. 字段规则

路径是评审映射，现有C1序列化名称以真实类型和兼容方案为准。N=必填、C=条件必填、D=派生只读、O=可选；没有工程依据不预填物理数值。

| 字段族 | 要求/单位 | 编辑者、来源与校验 |
|---|---|---|
| resourceId/revision/schemaVersion | D；标识 | 服务端分配/读取，界面不得伪造 |
| expectedLockVersion | D；整数 | 草稿服务；不等同Rev.xx；每次保存更新 |
| base.kind/element.kind/role | N；枚举 | 资源工程师；未知kind只读/拒绝写入 |
| localFrame.origin | N；mm | 对所属父帧；必须显示父帧名称和修订；不采用屏幕坐标 |
| localFrame.xAxis/zAxis | N；无量纲 | 单位且正交；显示y=z×x；非法输入不能静默正规化为制造事实 |
| mounting/child interfaceRef | N/C | exact定义中的真实ID；兼容key只是筛选提示，不代表所有尺寸/承载已匹配 |
| placementCapability | C；mm/整数 | 资源允许域；Grid轴/节距/索引边界、槽/轨道方向与行程 |
| datum.id/role/frame | C；mm、单位向量 | 用户命名并确认角色；点/面选择带geometryRef、modelRevision、frameId |
| display/collision assetRef | C；hash、format、来源 | 分别列出；必需碰撞资产遵循当前发布门，不造默认资产 |
| min/max opening，gripDiameter | C；mm | 厂商资料或受审测量；范围关系必须有效，不能由显示模型尺寸猜测 |
| actuationCapability | C；枚举 | 名义能力；ratedPressure沿用typed的bar，vacuum沿用mbar并明确表压/绝压语义 |
| ratedForce/preload | O/C；N | 为拟议扩展；字段缺失显示未提供，禁止仅由额定压力推定夹紧力 |
| friction/loadCase | O/C | 特定接触/使用条件；评估需要时必填来源、单位、版本与有效条件，不写入通用默认摩擦 |
| mounting selection/opening | C；Setup域 | 实际格点/槽号/位移和计划开口，落D04，不改D03允许域 |
| currentActuationState | D；执行域 | 观测或执行回执来源；与计划值并列，未知不显示“已夹紧” |
| assessment status/evidenceRef | D | 服务端返回；列结构、接口、定位、单边封闭、载荷、碰撞、运行确认各项 |

角度输入可显示°，提交边界一次转rad；Wire单位和原输入单位保留可追溯。真实材料/载荷/温度与公差只引用批准来源；占位示例必须标“演示值”。

## 4. 选择—预览—确认

树、列表、3D的选择共享引用，不传Babylon mesh作为领域身份。点击接口高亮并定位参数组；选择工具的状态显示在标题下，Esc取消本次选择、恢复焦点。引用失效时可以继续查看，但“确认基准”禁用且显示修复入口。

接口预览使用单独overlay和previewId，携带输入指纹。拖动只提出候选安装参数；最终Apply由后端重新解析允许域和精确帧。自动落座/对中基于同一草稿锚点产生绝对候选，反复点击不能在上次结果上叠加位移，也不能顺带扩展毛坯。

范围值超限时显示实填值、允许区间和来源；不自动clamp。组件的显示开口可以临时预览，但不得修改已发布资源或当前实夹紧状态。

## 5. 异常与关闭状态

| 状态 | 界面行为 |
|---|---|
| 空目录 | 显示新建/导入入口；不偷偷安装默认夹具 |
| loading/validating | 局部忙碌与真实任务阶段；流光只在任务运行时出现 |
| dirty关闭 | 保存草稿/放弃本次编辑/返回，三个动作明确；关闭容器不删除资源 |
| readonly | 标明历史发布/权限/未知模式原因；不靠禁用颜色单独表达 |
| conflict | 保留本地草稿，显示服务端新版本与比较入口；不自动覆盖 |
| preview failure | 清理当前preview，保留已提交几何；错误含字段与恢复动作 |
| late response | 错作用域/epoch不应用，日志记载来源；不切回旧文档 |
| unknown assessment | 显示缺失条件与“补充资料/更换模型”入口；不包装为成功 |
| stale assessment | 列出发生变化的依赖；重新检查前不能沿用旧指纹 |
| offline restore failure | 显示缺失闭包；保持原工程可见与可继续使用 |

Tab顺序：任务导航→对象列表→参数→错误摘要→主操作；Enter不应从输入框误触资源发布。键盘与3D选择都可回到对应字段；焦点关闭后回到原调用按钮。状态栏承载帧名称、单位、只读和任务信息，避免角落HUD遮挡。

## 6. 评审走查脚本

走查A：Setup-A发起选择→资源r1预览→切至Setup-B→A回执晚到→B不变→回A仍保留草稿。走查B：创建夹具→只提供显示网格→缺碰撞/精确基准提示→允许保存合法草稿但不能伪造发布/工程通过。走查C：六定位点分析rank=6→仍显示脱离反例→补夹紧资料→载荷未知保持未知。走查D：改变安装位置→仅相关检查stale→主题切换不改变工程修订。
