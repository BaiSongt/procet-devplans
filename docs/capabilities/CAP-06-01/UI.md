# CAP-06-01｜单Babylon世界与统一左TaskPanel
浅/深主题，最大字体12px；RendererPort单世界承载目标、毛坯、保护区、候选去料体与残余状态，右Agent只显隐不建第二Scene。GUI、CLI与Agent只调用同一SolverDomainPort。
| 用户操作/异常 | 任务面板 | 3D表现 | 领域结果 |
|---|---|---|---|
| A无D05但目标和毛坯齐 | exact来源、Frame、预算 | Target与Stock叠加 | 允许受限探索 |
| 缺毛坯/保护域/错Frame | MISSING或UNKNOWN、补证动作 | 不扩大bbox、不隐去保护区 | 禁止材料求解提交 |
| 求解中 | Beam/Boolean耗用、执行工具、取消按钮与流光等待 | 候选层只读 | 不能把Job排队当采纳 |
| 多候选 | D06 stable ID、排序/可靠值口径、每项D07状态 | 分解去料与材料变化联动，不做材料扫掠动画 | 选择只预览 |
| D08冻结冲突 | 冻结Owner/hash、影响子图、拒绝原因 | 冻结层锁定 | 转05域授权处理 |
| 取消晚回执/预算超时 | UNKNOWN或CANCELLED、任务代次/错误码 | 旧预览隔离 | 不改已冻结资产 |
