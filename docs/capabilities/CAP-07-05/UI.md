# CAP-07-05｜单Babylon世界与统一左TaskPanel
统一ActivityRail「刀路」切入，左侧TaskPanel用紧凑行表呈现阶段树（粗/半精/精）、各阶段来源D07哈希短指纹、有效Setup和D08冻结徽标；右侧Agent浮窗不持有独立业务真相。字号上限12px，浅/深主题；显式键盘焦点和可访问性对比度；未认证结果始终显示UNKNOWN/NOT_RUN，不允许仅以绿色表示PASS。

唯一Babylon Scene复用资源，OverlayLease使用`workContextId+setupId+stageId+revision+taskGeneration`作为租约键；显示粗加工前/后目标与去料体时只展示**真实归档D07证据**，合成用例必须水印SYNTHETIC。对可视CL的动画显示「刀路预览·非NC验证」。D13/D14/D15可作为分层诊断信息展示，但绝不混入CL图层的认证色。

用户交互：选择阶段→Owner.readExact→核对Frame→选择/调整余量→只读预览→显式采纳→CAS/ACL/generation重验→创建新D09修订；选择其他Setup、取消、模式A/B切换时撤销预览租约而不是删除真实D08。Agent的计划建议与CLI命令执行使用同一个07域Port。错误需要保留脏稿、原因、恢复建议；过期任务回执被拒且不可改变活动Scene与Owner事实。

评审与测试：键盘/缩放/DPI、30次空间往返GPU回收、晚回执、同Setup不同revision互串、A/B同事实、未知材质与夹具响应仅列**待真实浏览器和领域Owner执行**。L3/PASS及产品PASS均未授予。
