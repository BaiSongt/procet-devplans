# CAP-07-05｜独立消费者及迁移/回退
**独立消费方**：06域D07材料状态Owner、05域D08冻结Owner、08域D12后处理和09域D13/D14/D15验证，各由独立进程/测试用例通过公开契约读取新D09而非共享内部实现。验收必须给出精确SHA组合、Frame、Setup、消费端版本、命令、退出码及审计证据；**当前全部NOT_RUN**。

| 场景 | 消费者真实应验事实 | 反例与恢复 |
|---|---|---|
| 粗→半精 | D07前后状态顺序、体积有效性、局部特征保护 | 缺S1封存的真实后态，S2不得开始；退回只读诊断 |
| 半精→精 | 精加工使用S2最新有效后态、留量和实际刀具 | 旧工具修订或Frame漂移，禁止误用旧Stock |
| CL→NC | 08域从D09中立CL后处理生成D12并记录revision/hash | 无D12或控制器差异，D13必须UNKNOWN |
| 控制器→轴时序 | D13语义适配实际D10机床运动链，D14真实时序 | 未建模指令/轴限/奇异分支则Fail-Closed |
| 验证→发布 | D15独立工程验证含机床/刀柄/安全门禁后D16审批 | CL动画、2D截图或半精阶段指标不得替代D15 |
| A/B接管、取消 | 所有消费者读同一D08、D09谱系，晚回执隔离 | expectedHead冲突或cancel后只保留草稿 |

**兼容迁移**：Expand为D09添加可选stageStrategyVersion、sourceD07Ref、allowanceIntent，旧消费者忽略新增字段；Migrate以快照引用创建新D09修订、绝不覆写旧冻结；Contract仅在独立消费者真实PASS且人类批准后退出旧读取器。回退至可读旧D09与原D08快照，不删除用户数据。来源哈希缺失、未知NC或实际产品测试失败时保持BLOCKED，不自动生成伪结果。
