# CAP-08-02｜控制器方言 GUI/3D 交互规格

唯一Babylon Scene和统一左侧UnifiedTaskPanel；NC/后处理活动入口不建立新主视口。Ribbon选择执行绑定后，左TaskPanel的五个紧凑段依次为：①控制器精确型号/软件/选件/配置Hash；②白名单/未知功能筛选；③初始模态与WCS/刀补核验；④NC物理行→D13规范事件→D14时序→D15工程结论三向追踪；⑤人工签署前的CAS、权限、取消与版本状态。GUI、CLI、Agent调用同一08域DomainPort，仅08域Owner可以写D12/D13。

可点NC行并在单Scene中高亮D09关联段与D04/D10 Frame，NC解释未知处显示橙线定位和明确`UNKNOWN: source line, command, profile limitation`。CL几何动画标`仅预览`，D14轴播放标`依据NC执行语义`，D15未测标`NOT_RUN`；绝不合并成一枚“已验证”按钮。任务执行状态以真实阶段流光提示，不伪造百分比，最大字号12px、仅浅色/深色主题，悬浮工具条不遮挡视口。

取消应释放预览租约且不删除历史NC；切换Setup、控制器Profile、工程版本后主动重新读exactRef并将旧显示置STALE。权限撤销/CAS冲突/晚回执/未知宏均在TaskPanel给出可定位诊断，UI不进行补偿语义推断。
