## 业务流程与交付
1. 严格读取D08、D09的exact身份/哈希/Frame/单位与D10机床/刀柄/偏置/控制器Profile，绝不默用latest，也不由B5名称猜五轴结构。
2. 选择来源、许可证、二进制SHA与配置SHA都固定的后处理器，预检查controller方言、LINE/ARC/HELIX/刀补/TCP支持能力、单位/平面/距离/WCS/进退刀及modal初态；未知宏、循环或RTCP明确UNKNOWN。降级插补须记录误差并生成新版本。
3. 生成**临时**NC与逐行来源；合成header/trailer等须标SYNTHETIC+原因，NC完整原始字节SHA独立于结构化配置JCS哈希。重复输入全文hash稳定性需要真实post端验收，规划不冒称已运行。
4. GUI/CLI/Agent全部调用同一`PostProcessingPort.preview/commit/cancel/forkManualEdit`。commit时重新进行项目scope、ACL、CAS(expected/current)、Frame/hash与任务代次检查；取消晚回执只读审计，不能采纳。
5. 仅采纳不可变D12新修订；人工改NC要fork与重审行段映射，不可覆盖已发布版或D08冻结。变更D10/post/D09必须使相关D12→D16失效、保留旧NC只读供追溯，不删除数据库。
