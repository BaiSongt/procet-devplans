# E3-04｜GUI / CLI / Agent / 单Babylon世界与3D轴播放规划

## 唯一领域入口

GUI「NC工作台→机床运动」打开左侧统一TaskPanel中的同一任务，CLI `procet motion expand --d13 <exact> --d10 <exact> --d03 <exact>`及Agent工具`machineMotion.expand`必须由Host路由至`MachineMotionExpansionPort.expand`，不能各自实现独立IK或改变D08/D12/D13。仅浅色和深色主题，最大字号12px；面板图层可调整而不创建第二Babylon世界。

## 五步UI状态机

| 步 | 用户操作 | 只读状态/错误 |
|---|---|---|
| 1 NC事件 | 选择D12→D13精确版本，查看语义覆盖 | UNKNOWN立即显示未支持行/原因，无可播放“成功” |
| 2 机床配置 | 绑定D10、D03、Frame、刀柄与测量来源 | B5真实轴树/旋转中心缺失时“待校准”，阻断验收 |
| 3 模式 | 查看AXIS_ADDRESSES或TCP_POSE分流及配置来源 | 不能允许双重IK，RTCP状态不明提示UNKNOWN |
| 4 计算与预览 | 从3D世界现有节点播放候选的关节运动，查看时序、姿态、来源行 | 按“估算/未知”区分时间，CL动画/静态姿态只可注记示意 |
| 5 采纳/交接 | 审核D14来源闭包，提交expectedRevision并移交D15 | 权限/CAS/cancel重验，晚回执仅审计，D15未验禁止发布 |

## 3D图层与交互门禁

左TaskPanel包含NC行号、轴时序、逐节点旋转中心可视标记、选择的IK分支、TCP/刀柄轴向、限位警告、模态来源；3D工具条不遮挡，统一Babylon世界仅存在一份机床变换图。高亮夹具/模型坐标轴而不写入业务事实。拖动播放滑块是只读时序消费，**不是人手修改真实机床配置**。采纳是独立按钮且默认禁用：输入是合成模型、B5配置UNKNOWN、D13不READY、碰撞/限位证据不足时显示对应门禁。

## 独立消费者

D15验收程序化读取D14版本化事件并复算来源哈希；GUI不得根据3D动画流畅程度标记D15 PASS。真实设备限位、碰撞、反向轴运动和工具装配测量由09域验证和现场工程双方签署；本规划未执行。
