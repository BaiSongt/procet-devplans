## 1. 业务边界、Owner及不可替代的审批

D16唯一领域Owner候选为**10域程序发布与现场协同**；D17记录现场**接收**事实，与实际机床加工/测量结果不同。D16不是D12后处理器、D13执行解释器、D14仿真器，也不是D15验证计算器；它是对真实D12原始字节、D10机床执行绑定、D13已建模语义、D14轴运动证据和D15独立验证结果进行精确闭包检查后，生成**受控候选与审批/离线交付记录**的独立领域。D04名义Setup不自动替代D10执行偏置；D08冻结快照只读且不可静默覆盖。

D09中立CL → D12后处理生成最终NC → D13按精确控制器配置解释 → D14轴运动展开 → D15 NC程序级工程验证 → **D16独立检查与人类审批** → D17离线接收回执。D11/CL视频可作旁证，**不能授予D15或D16资格**。D15离散采样结论须如实记录覆盖/不确定性，不是连续全程无碰撞证明。本规划不实现材料扫掠仿真、不触达真实设备、不替客户作生产批准。

D16状态区分 DRAFT → ELIGIBILITY_UNKNOWN / PENDING_HUMAN → APPROVED → PUBLISHED，并支持 REVOKED / SUPERSEDED；执行资格必须绑定策略版本与同一NC闭包。**D15 PASS 或本规划JSON规则PASS均不会自动变为 APPROVED/PUBLISHED**。授权角色、独立审查及签署证据必须按客户现场策略由人类确认。

## 4. 离线包协议、信任边界与接收步骤

1. 签发前对最终NC字节和附件逐一生成内容摘要；完整清单中固定每个相对路径、长度、SHA-256、工程作用域、D08/D10/D12/D13/D14/D15精确引用，审查真实必选覆盖和批准记录。
2. 对manifest JSON使用明确版本化的JCS规范化方案，签名载荷、签名算法、keyId、密钥轮换、信任根分发及证书撤销门禁在安全评审后确定。**只附包内公钥不能建立信任**；接收方信任锚必须事先独立配置。原始NC直接按字节Hash，不执行JCS。
3. 离线D17接收方在完全断网条件下**重新计算**NC/所有文件摘要，阻止绝对路径、反斜杠绕过、..、符号链接与同名替换；用预置策略及信任根独立验签并核对授权发布者、scope、机器/控制器版本、撤销快照的新鲜度。
4. 未获得必要撤销信息或验签组件失效时，结果只能为UNKNOWN/REJECTED，不因现场断网降级成可信。拒绝包保留只读诊断（不得执行）。
5. D17出具独立追加的接收回执：工件摘要、接收站标识、策略版本、时钟可信度、幂等键、查验结果和原因。**仅表示已接收/校验，绝不自动表示运行完成、工艺批准或设备控制。**

发布包样例为虚构元数据和占位Hash，emissionAllowed=false、签名NOT_RUN；不得从样例生成真实发布包或误认有效FIPS签名。

## 5. 接口、GUI/3D、失效和迁移

Host受管Port统一请求字段：project/document/setup作用域、principal、expectedRevision、idempotencyKey、cancelToken、exact输入refs。GUI左侧统一TaskPanel显示来源闭包、必选覆盖、批准责任、签名/离线验签和回执；同一个Babylon Scene复用RendererPort，只做证据定位，不因选中、播放或预览修改D16事实。CLI与Agent使用同一受管Schema，禁止绕过CAS、ACL、生命周期门禁直接写DB/下发机床。

发布状态以**append-only**事件流管理。NC/控制器profile/机床配置/D15策略/审批权限更新仅使相关当前资格STALE，并生成新的可审查修订；不得删除历史批准记录、覆盖冻结结果或隐式重置用户数据库。已发往现场的旧包不能被远程假称收回：应生成撤销公告、标记发行/接收时序及现场确认状态；无法联机确认时保留 UNKNOWN_RECEIPT。

迁移先接入V0.7只读适配，缺少NC字节SHA、签名或验证覆盖信息的旧包仅供历史浏览，不提升为受控可发资格。回滚D16协议应重新审查所有已签名Manifest的schema与验签兼容性；不拆解历史链，也不改变产品源码仓。

## 6. 执行验证和交接

规划校验工具只检查规则、来源、资产及合成正反验收映射；不是真实密码学、NC、机床或独立D17的验证程序。产品阶段必须用三轴及经校准的B5合法基线、真实控制器金样、受控签名测试钥匙、断网接收机、篡改/撤销/并发/旧包/错机床/错NC案例开展双人独立验收。NIST FIPS/RFC/in-toto/SLSA仅支撑适用**片段**的工程设计思路，不宣称Procet已通过任何标准认证。**规划PASS≠产品PASS。**
