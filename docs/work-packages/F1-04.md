# F1-04｜分离探索输入、工艺Setup与机床执行绑定

**2026-10-18；实施级规格草案已编制，待评审／产品未实现未验收。** 原36项工作包编号、B0-02/B0-04/F1-01/F1-03依赖不变。本文于2026-10-18初次编制，入库状态以仓库当前分支及提交记录为准。

## 目标与流程
用户角色：CAD设计员进行源模型和几何探索；工艺员定义毛坯、工艺基准和装夹；数控员选择实际机床与控制器；质量员审查NC执行证据；Host/Project持久化与权限。A探索、B生产共享版本资产与同一领域服务，A模式的候选不能覆盖B已批准的冻结资产。

主线：D01 CAD浏览→D02特征候选→按实际条件进行材料求解D06/D07→D04工艺Setup与D05计划审批→D08冻结→D09中立CL→D10机器执行绑定→D12最终NC→D13语义解释→D14轴时序→D15验证→D16发布。

**规划分拆（L3待审，不是已有DTO）：** ExplorationInputRevision记录D01、Frame、算法约束与任务来源；ProcessSetupRevision属于D04，记录工件加工基准、初始Stock及装夹约束；MachineExecutionBindingRevision属于D10，引用精确机床/控制器/后处理配置及D04版本。三者不能被误建为三个新Host或数据库真值。

替代流程：纯几何探索可没有Machine；材料去除计算**必须具备初始Stock及Frame**；B生产可以直接选择已批准工艺不必重做特征分析。机床不可用或未知时不能假定后处理/NC发布可行。确认或批准操作必须经后端用相同requestId/expectedRevision重新校验，3D预览永不写权威业务。

## 能力门禁：按阶段而非全局
| 阶段 | 最小输入 | 输出资格 | 不可做的假设 |
|---|---|---|---|
| CAD浏览 | exact D01与实际读取得到的几何证据 | 只读浏览 | 无机床不能直接禁止浏览；mesh-only非可制造BRep |
| 特征探索 | BRep/Frame/算法版本 | D02候选 | 候选≠Accepted |
| 材料搜索 | D01目标+明确初始Stock与Frame | D06/D07候选、独立核验状态 | 缺Stock不能求“真实”材料状态 |
| 工艺规划/批准 | D04确切工艺条件、D05草稿与角色批准 | D08冻结版本 | 不能把A候选自动升格 |
| 中立CL | 冻结工艺条件及刀具/策略 | D09及可选D11 | CL不含厂商轴树也不代表NC验证 |
| NC执行/发布 | D10确切机器/控制器/后处理+D12最终NC和D13/D14/D15 | D16或结构化失败 | 缺宏/TCP/RTCP的执行解释不得PASS |

阶段要求采用候选状态ready/blocked/unknown/not_applicable，须携带sourceRefs、fieldPath、恢复动作；四态为本产品设计决策，不是ISO强制。GUI/CLI/Agent共享Host和领域命令入口，能力登记、后端就绪、当前请求许可和实际提交分别验证。系统不做材料扫掠仿真。

## 领域输入、Owner与字段约束
D01/D02归03域；D03归02；D04/D10归04（D10引用02）；D05/D08归05；D06/D07归06；D09归07；D12/D13归08；D14/D15归09；D16归10。公共C0只保留DomainRef、单位/Frame、修订/协议，C1字段归各Owner。字段均为L3提案：sourceRefs/topologyHash/sourceFrame只读来自CAD；stockRef/stockFrame为D04，长度mm且不能自动扩毛坯；processFrame/approvalRef归D04；machineRef/controllerDialectRef/postRef/g5xMapping/toolAssemblyRef与gaugeEvidence归D10；requestId/expectedRevision/routeEpoch/sessionEpoch/receipt由Host及提交服务负责。缺单位、Frame、设备轴树、控制器方言只能unknown，不得凭型号或显示外观猜测。

**已读产品源码基线（只读观察，不代表测试通过）：** procet-cam@fcec1c86047e6b11be35b8bb38971e3dfcffbd7b 的 src/cam/setup/manufacturing/types.rs、preflight.rs、src/facade/mod.rs；procet-gui@4e8eec12a212fc9dc86f2d728762c852832eebdb 的 apps/desktop/src/modules/cam/setupWire.ts、apps/desktop/src-tauri/src/commands/cam.rs、modelInput.ts。现有Setup需要machineRef且在Machine CSYS中放置Stock/MCS，GUI创建Draft用100×100×50和G54只是编辑起点，**不是工程标准或默认资格**。逐步迁移须保留旧Approved读兼容，不能删生产门来冒充新能力。

拟议GetStageRequirements、PreviewExploration、CreateProcessSetupDraft、ApproveProcessSetup、CreateExecutionBinding、ValidateExecutionBinding、InspectReceipt是目标用例名，**不是已存在接口**。可执行测试入口目前确认的只有cam边界审计`cargo test --locked --test boundary_audit`，不覆盖本规划验收，本轮未执行。F1-04专用真实Rust/TS/IPC/NC/恢复测试入口均待实施后核对。
