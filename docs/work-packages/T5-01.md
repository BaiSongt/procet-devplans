## 真实业务流程与状态
1. 用户在Ribbon/Agent浮窗/左TaskPanel、CLI或受控Agent发出同一`DomainToolIntent`；记录`WorkContextRef(project,document,setup,revision,contentHash,frameRef,scopeEpoch)`，校验调用身份、工具描述版本、所申请的能力及数据ACL。
2. **先取证、后建议。** KnowledgeProvider按业务ACL/可见集合搜索；每条命中保存assetId、修订、内容hash、文档页/段或STEP元素定位、索引版本、引用可见范围、检索时间。检索文本、OCR、第三方工具返回的自然语言均是**不可信数据**，不能授予指令或扩大工具权限。来源缺失返回`EVIDENCE_GAP`，不虚构引用。
3. 复用宿主的共享LLM Gateway，不独立复制客户端/密钥缓存。调用回执固定`toolCallId / idempotencyKey / toolSchemaVersion / modelId / protocolVersion / stage / status / ownerRevision / reasonCode`。允许`QUEUED→RETRIEVING→REASONING→WAITING_TOOL→AWAITING_APPROVAL→COMMITTED`，以及`CANCELLED/FAILED/STALE/UNKNOWN`分支。模型输出“已完成”并非Owner成功回执。
4. **区分建议、试算、批准、提交。** Agent只生成候选、解释和受控命令意图；D05人工批准和D08冻结由05域Owner受控提交。D06求解器、D09 CAM、D13 NC控制器、D15验证服务均独立判定，不受自然语言暗示。用户撤销授权、scope切换、Frame失配、输入版本漂移时禁止提交。
5. Owner提交前重读expectedHead、revision、contentHash、frameRef、ACL epoch、taskGeneration、cancelToken与approvalRef，并以CAS原子决议。过期/取消后晚回执归原task审计，不刷新新工程状态；相同idempotencyKey的重试不能重复执行。
6. A/B共享精确工程事实，AI仅给独立候选，不覆盖D08冻结快照。D04工艺Setup≠D10机床执行绑定；D09中立CL→D12 NC后处理→D13控制器执行语义→D14轴时序→D15程序级验证→D16审批发布。CL动画或D11预演**不等于D15**；未知专有语义一律`UNKNOWN`并阻止自动发布；**不做材料扫掠仿真**。

## 字段、Ownership与权限
命令意图（**非持久化领域结果**）包含`actorId/authorizedRole/approvalRef`、`projectId/documentId/setupId`、`expectedRevision/contentHash/frameRef/scopeEpoch`、`aclEpoch/taskGeneration/cancelToken/idempotencyKey`以及工具schema/model/provider/protocol版本；若字段未知，一律`NEEDS_REVALIDATION`。只允许通过`owner.Dxx.readExact`取得受控证据；只有域Owner`commitCAS`能够改变该域资产。AI KnowledgeIndex是索引视图，不是D01设计或D08冻结资产的第二写入者。[17资产候选责任界面](T5-01/asset-owner-candidates.json)逐项列出候选Owner；正式会签均PENDING，不声明接口已实现。

内部错误码：`EVIDENCE_GAP`（来源断链）、`ACL_DENIED`、`STALE_REVISION`、`FRAME_MISMATCH`、`CANCELLED`、`UNKNOWN_TOOL_SEMANTIC`、`MODEL_COMPAT_UNKNOWN`、`OWNER_CONFLICT`；不允许从UNKNOWN隐式升级PASS。审计日志只留允许的摘要及相关ID，禁止上传私钥、客户真实图纸、原始生产NC或完整敏感提示。

## 迁移、回退与验收
旧工具及知识读取器先Expand成为只读适配，在新旧引用结果逐条比对后Migrate，达到固定组合下真实独立消费者PASS及人类批准后再Contract；禁止双写。能力关闭时返回`READ_ONLY_ADVICE`且保留引用和用户未提交草稿，不能删用户数据/冻结记录。每项必须用真实独立进程读取Owner提交回执、权限撤销、强杀/重启、异步晚回执和消费版本，并记录产品exact HEAD / 模型ID / Schema / 测试日志hash。
