## 原目标及范围
依据[V0.8原36项](../architecture/v0.8/04_开发工作包_36项.md)保留目标：**2D产品锁与界面适配；图纸/OCR证据经人工确认；快照恢复回归**。目标产品仓procet-2d、procet-docs、procet-gui（这里只规划不修改）。前置U4-06、F1-06。拒绝承诺通用2D→3D、自动识别的PMI有权威性、自动修改几何。

## 从图纸到采纳的真实业务链
1. 读取受权D01原图文件`documentId/revision/rawBytesHash/mime/size`与页面或DXF实体路径；分别钉住procet-2d、procet-docs、GUI、OCR模型、解析器的exact Git SHA/build hash，不以浮动develop构建产品锁。文件hash不一致返回`SOURCE_UNVERIFIED`。
2. DXF线、弧、标注实体保留handle/layer/block path；把`OCS→WCS→ProjectFrame`和INSERT位置/方向/单位作为可审计矩阵链保存。遇镜像或非均匀缩放/未知单位时不按屏幕像素重建毫米。PDF必须记录pageIndex/CropBox/Rotate/viewTransform/标定证据；扫描图纸缺有效标定只允许页面预览，禁生成尺寸事实。
3. OCR生成`EvidenceCandidate(rawHash,pageId,bbox,engineVersion,languagePack,text,confidenceMeaning,status=CANDIDATE)`。来源图片/OCR文本均为不可信业务输入，不可触发工具指令。OCR对直径、公差、基准符号识别错误，必须显式允许人工更正，不得自动成为D01或D02权威PMI。
4. 把候选的`SourceLocator`关联`GeometryRef(modelRevision,geometryHash,frameHash,subshapeId)`；重复标注、多义公差、目标不在已审批CAD修订上时返回`NEEDS_HUMAN_LINK`，不以三维画面邻近选择冒充关联。
5. 用户在统一左TaskPanel查看原图/OCR框/3D目标和来源差异，明确采纳/拒绝理由。03域Owner重新校验ACL、scopeEpoch、CAS expectedHead、Frame、来源hash、taskGeneration及cancelToken，提交**新**D01/D02修订；只读A/B共享同一事实，不覆盖D08冻结，人工门禁不被Agent绕过。
6. 快照恢复须同时校验来源hash、解析器与模型锁、坐标变换及采纳链；旧reader兼容，`LEGACY_UNVERIFIED`降级只读，撤回只生成新采纳撤销记录，不删除原图、草稿、D08或用户数据库。
