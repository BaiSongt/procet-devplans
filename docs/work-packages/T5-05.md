## 领域端口、数据与质量门禁
只共享C0最小identity、unit、FrameRef、revision/hash、scope、协议，不造巨型common。候选字段：`SliceInputRef{assetId,exactRevision,contentHash,FrameRef,scope,ownerId,schemaVersion}`、`SliceRun{sliceId,producerCommit,consumerCommit,binaryLockHash,goldenHash,toolchainABI,taskGeneration,cancelToken}`、`DomainCommand{expectedRevision,expectedHash,aclEpoch,scopeEpoch}`、`Evidence{consumerProcess,exitCode,logHash,class}`。字段为待评审设计，不宣称已实现。

所有GUI/CLI/Agent调用同一领域Owner接口，提交**当刻**重核CAS/ACL/Frame/作用域/任务代次/取消状态；取消晚回执只进旧任务审计。真实Provider+独立Consumer进程必须通过同一脱敏Golden和Schema/hash/Frame/unknown负例，新成员在离线环境复现并保存exact版本、日志SHA及退出码；不能由Mock/合成脚本代替。A/B共用同一受控事实引用，不能双主写；恢复保留旧Reader、D08冻结、D16/D17历史及用户库，禁止伪造跨存储ACID。
