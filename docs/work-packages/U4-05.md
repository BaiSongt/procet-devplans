## 基线、不变职责与验收口径
保留[原36工作包映射](../architecture/v0.8/04_开发工作包_36项.md)U4-05的原编号、依赖、交付和验收。11域、88项CAP、36原工作包、17类资产和L1/L2不变，L3尚需审定。C0最小公用只含身份、单位、Frame、revision/contentHash、scope及协议，不建UI巨型DomainStore。

**核心原则：** 最大字体12px是设计密度上限，绝非减小可点击目标、隐去焦点或豁免文字可读性的理由。主题只允许浅/深两个；12px普通文字依据WCAG 2.2 1.4.3默认按4.5:1核验，控件和状态标记按可适用非文字对比度核验。WCAG 2.2 2.5.8的24 CSS px目标允许明确的间距、等效等例外，不能机械把所有图标强制为24px视觉尺寸；完整网页/桌面符合性必须另做独立审计。单Babylon Scene及统一左TaskPanel是产品架构选择，不是Babylon官方强制约束。

## 数据契约、Owner、失效边界
输入`WorkContextRef(project,document,setup,revision,contentHash,frameRef,scopeEpoch)`和`UIProfile(theme,density,dpi,zoom,reducedMotion)`，产生的是只读`PresentationSnapshot/UXAuditRecord/OverlayLeaseReceipt`，不是D04-D16新的Owner事实。GUI/CLI/Agent调用相同`DomainUXQuery.readExact(scope,assetRef,aclEpoch)`与`TaskCommandPort.submitIntent(...)`；业务写入唯一经对应Owner的`commitCAS(expectedHead,contentHash,frameRef,aclEpoch,scopeEpoch,taskGeneration,approvalRef)`，在提交瞬间复查权限/版本/取消，晚到回执只记历史不可替换新UI。

D04制造工艺Setup≠D10实际机床执行绑定。D09中立CL→D12 NC后处理→D13执行语义→D14轴时序→D15独立工程验证→D16审批发布；D11/CL动画仅预演，未建模控制器语义显示`UNKNOWN`阻断发布，不设计材料扫掠仿真。A/B共享同一受控工程事实，D08冻结永不被UI样式、导航或批量性能测试覆盖。变更CSS或渲染LOD不得自动失效D08；变更资产source hash或Frame需Owner确认后独立计算影响闭包，未知依赖标`UNKNOWN_SCOPE`。
