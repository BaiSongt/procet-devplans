## 控制流与界面契约

```text
Key Escape / pointercancel / lostpointercapture
  → 归一化InputIntent (composition可信度、指针会话ID、sceneEpoch)
  → Host焦点/真实模态仲裁(IME优先)
  → EditSession(脏草稿须确认；PreviewLease可释放)
  → 仅显式业务确认才发目标OwnerPort命令
  → Owner重新验revision/hash/frame/ACL/scope/cancel CAS
  → 真实Owner回执再更新领域投影；晚回执作STALE
```

正常模态Esc只关闭当前对话框并归还焦点，不关闭整个WorkContext、提交或撤回制造修订；输入法组合中Esc不得透传到全局关闭。取消指针捕获后旧pick结果必须由sceneEpoch/leaseEpoch/GeometryRef共同否决。任务容器是**唯一左TaskPanel**；工程与制造资源空间横向切换时仍**唯一Babylon Engine/Scene/Canvas**、非活动root不可拾取，焦点或显示状态不增加领域修订。GUI/CLI/Agent共用04.EditSessionPort领域用例，Agent不以“执行成功文本”代替Owner回执。
