## 2. 安装链：符号固定比矩阵库名称更重要

采用列向量，`p_A=T_AB*p_B`；T_AB将B坐标表示映射到A。右手刚体R满足R转置R=I且det(R)=+1；位移是有限值，齐次末行是[0,0,0,1]。

父实例P有接口I，子资源C有接口J，明确配合关系T_IJ，则：

```
T_WC = T_WP * T_PI * T_IJ * inverse(T_CJ)
检查：T_WC * T_CJ = T_WP * T_PI * T_IJ
```

这是用SRC-TA-001的复合规则推导的Procet配合公式，不是厂商规定所有接口都同轴同向。两个接口是否需要反向或附加偏置，必须由版本化配合定义说明。源CAD合法镜像是几何导入变更；不能将反射矩阵伪装为安装刚体pose。

SRC-WH-007特别提示API语义：位移物体与改变同一点的坐标表达不能混用。实施时对实际锁定OCCT版本逐项验证，不为使用当前网页而升级SDK。

## 3. 一阶定位模型与脱离反例

设初始接触点r_i在同一分析帧，单位法向n_i朝向允许分离侧。对小运动(q平移、角增量θ)，间隙一阶变化为：

```
dg_i = n_i · (dt + dtheta × r_i)
     = [n_i^T, (r_i × n_i)^T] [dt; dtheta]
```

以声明的正特征长度L归一化：`A_i=[n_i^T,(r_i×n_i)^T/L]`、`q=[dt;L*dtheta]`。mm改m时r与L同步缩放，A不变。L的选择与秩阈值属于版本化数值策略，不能把示例1e-9当作微米级生产公差。生产端用归一化SVD和近奇异灰区，而不是只比较点数量。

保持全部接触的双边近似为`Aq=0`；rank(A)=6说明这一近似下没有非零自由增量。真实无穿透单边条件是`Aq>=0`，其中部分分量大于零表示脱离，不是接触失效代码可以随意忽略的自由度。[SRC-WH-002]

自建合成反例：3个底支撑、2个侧定位、1个端定位，矩阵可以满秩，但q=[0,0,1,0,0,0]仍满足全部间隙非负，工件可以向上离开底面。因此rank6不能被转换成“已完全夹持”。这些坐标仅用于数学反例，不是实际工装设计。

一阶形封闭要求只有零瞬时运动可行；等价条件需满秩并满足接触法向wrench的严格正组合平衡。它不是仅检测rank；未通过一阶条件时可能需要曲率或高阶信息，结果应标为本模型未证明。[SRC-WH-003] 本轮脚本只演示反例和秩，不实现通用LP形封闭判定器。

## 4. 摩擦、夹紧能力与受限载荷

在声明的非黏附Coulomb点接触模型中：`f_n>=0`、`||f_t||<=mu*f_n`。切向二维合力要取范数，不能分别把x/y都放宽到mu*f_n，否则会接受摩擦锥外的力。[SRC-WH-005]

对有限载荷还需满足各力/力矩平衡、接触/执行器上限及工况条件。没有载荷或预紧资料时，不存在可依据的安全裕量。力封闭只说明理论wrench方向覆盖，不保证执行器有足够幅值。[SRC-WH-004]

Procet设计选择：数值项同时记录value、unit、sourceRef、validConditions及修订。未知μ不是0也不是经验默认值；允许unknown报告。压紧、磁吸、真空和黏附是不同接触模型，不能把负法向力塞进普通单边接触以伪造通过。刚体/静力模型不能证明薄壁变形、振动或实际节拍。

## 6. 资料缺口和工程冻结条件

需取得实际夹具/机床接口图、安装规程、驱动能力曲线、夹紧确认方式、工件与接触材料、载荷谱及适用公差，才能冻结具体生产配置。ISO 5459正文未取得时，GPS自动解释保持独立补证门。跨版本OCCT函数行为、用户工件接触提取、弹性/热态、完整碰撞都未在本轮验证。

这不阻止规格评审和有明确unknown的原型开发；它阻止把无依据数值或范围外模型当作已认证能力。
